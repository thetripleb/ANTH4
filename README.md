# ANTH4

Intro to Linguistics Study Repository — Anth 4

## Setup

1. Open https://thetripleb.github.io/ANTH4/ in your browser
2. Go to **Manage Data > GitHub Sync**
3. Enter your GitHub PAT (Contents: read/write on this repo)
4. Click **Save & Connect**

Data is stored in `anth4_data.json` and syncs automatically across devices.
